# אהרון פרקש – דף נחיתה

אתר סטטי (HTML / CSS / JavaScript) בלי שלב build ובלי תלויות.

## מבנה
```
index.html           דף הנחיתה
privacy.html         מדיניות פרטיות
accessibility.html   הצהרת נגישות
styles.css           כל העיצוב, כולל מובייל (נקודות שבירה 1180 / 900 / 420)
main.js              אנימציות ואינטראקציות
assets/              תמונות ואייקונים (WebP / PNG)
fonts/               Tel Aviv Brutalist (Bold / Regular / Light)
vercel.json          הגדרות Vercel (כתובות נקיות + cache לקבצים סטטיים)
```

## הרצה מקומית
לפתוח את `index.html` בדפדפן, או: `npx serve .`

## העלאה ל-GitHub
```bash
cd aharon-perkash-landing
```

## פרסום ב-Vercel
Add New → Project → בחירת הריפו.  Framework Preset: **Other**, בלי Build Command, Output Directory: ריק (שורש).

## אנימציות (main.js)
- נקודות שנדלקות סביב הסמן (הירו, הגישה שלי, שיטת הרמזור, FAQ). במובייל נודדות לנקודות אקראיות בגלילה. מתעמעמות ל-20% מתחת לטקסט.
- רמזור הפתיחה בהירו נדלק אור אחרי אור.
- קרוסלות המלצות אינסופיות; במעבר עכבר רק הכרטיס המסומן עולה.
- קומפוזיציית האשראי: עמודות ההוצאות, פס המסגרת והאייקונים על העיגולים רצים 3 פעמים כשהסקשן נכנס למסך.
- מרקר "זה יקרה." נצבע בבת אחת כשהתיבה כולה במסך (בכל חזרה).
- "ותוך שנה מהחתונה" – הכותרת נצבעת מילה אחרי מילה (בכל חזרה).
- שלבי הרמזור: כבויים, מהבהבים 3 פעמים בכניסה למסך ונשארים דולקים; קו נקודות מעוקל מתמלא לפי הגלילה.
- FAQ: שאלה אחת פתוחה בכל פעם (הראשונה פתוחה כברירת מחדל), פתיחה רכה.
- כל האנימציות נעצרות כשמוגדרת במכשיר העדפה להפחתת תנועה.
